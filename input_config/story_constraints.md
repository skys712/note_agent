# 故事级约束

> 最高优先级，所有大纲设计和正文写作必须严格遵守以下约束。

## 时间线规则

- 这是「分歧时间轴1」——命运(17号)从未干预过的时间线
- **命运(17号)在本故事中不存在、不出场、不被提及**
- 武祖在卡门线战役中战死，没有被任何人救下
- 心灵被外神污染后独自强撑将庙祝带回西方
- 没有救世主，没有任何超越性的力量干预历史进程
- 所有剧情事件必须来自碎片中关于分歧时间轴1的描述
- 不得引用分歧时间轴2中命运救场、武祖存活的任何设定

## 禁止出现的元素

- 命运 / 17号 / 第十七号操作员 / 命运的投影 / 命运的干预
- 武祖被救 / 武祖存活于卡门线之后
- 任何形式的「救世主」或外部超越性干预
- 半位面监狱
- 时间线被修改 / 命运改变历史进程

## 允许的核心设定

- 外神 / 虚空海 / 灵能 / 奥术体系 / 武者体系 / 信仰神 / 庙祝
- 宇宙碎片 / 死亡沙漠 / 东方大陆 / 西方大陆
- 水之大魔导师(大裂解术) / 土之大魔导师(黑洞术) / 心灵(认知覆写) / 庙祝姑娘(歌姬体系)
- 武祖的遗产(剑/记忆/武者协会)可以存在，但武祖本人已在分歧点战死

## 修正项
- 歌姬 出现在 庙祝到西方大陆后。歌姬和庙祝是同一体系下的不同称谓。不要过早出现歌姬元素，不要和庙祝混用。
- 不要使用任何一个分歧时间线2的元素：研究员故事、半位面监狱、囚犯
- 导师只能作为旁观者出现，不参与任何剧情的推动。在任何剧情元素中都不要出现。
